# EPOCHE Stack (Read-Only Mirror)

This repository is a read-only mirror of the EPOCHE Stack — a collection of independent, non-authoritative, non-operational interpretive documents examining escalation, uncertainty, mimicry, and restraint in adversarial AI contexts.

The materials presented here are advisory-only and exist for archival visibility, reference, and verification. They do not constitute a system, framework, implementation, or operational capability.
